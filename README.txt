UniDownloader 3  -  طريقة الرفع والبناء (من المتصفح فقط)

1) في GitHub أنشئ مستودعاً جديداً اسمه UniDownloader واجعله عاماً (Public).
   (العام ضروري ليعمل التحديث التلقائي وروابط التحميل بدون مفاتيح)

2) فك ضغط هذا الملف، ثم ادخل صفحة المستودع واضغط:
   Add file  ←  Upload files
   واسحب كل محتويات المجلد (الملفات + مجلد extension + مجلد .github) إلى الصفحة.
   ثم اضغط Commit changes.
   * إذا لم يظهر مجلد .github بعد الرفع، أخبرني لأعطيك طريقة أخرى.

3) افتح تبويب Actions، وانتظر انتهاء البناء (حوالي 3 إلى 5 دقائق).
   ثم من صفحة المستودع ← Releases ← حمّل UniDownloader.exe

4) شغّل UniDownloader.exe مرة واحدة:
   - ينسخ نفسه تلقائياً ويصنع اختصاراً على سطح المكتب وفي قائمة ابدأ ويعمل مع ويندوز.
   - من الإعدادات اضغط «تثبيت إضافة كروم / إيدج» واتبع الخطوات الثلاث.

5) للتحديث التلقائي: في الإعدادات اكتب اسم المستودع بالشكل  حسابك/UniDownloader
   وكل مرة ترفع فيها تعديلاً يبني GitHub نسخة جديدة، والبرنامج يعرض «توجد نسخة جديدة».

ملاحظات:
- أول تحميل فيديو ينزّل yt-dlp و ffmpeg تلقائياً مرة واحدة (حوالي 100 ميغابايت).
- yt-dlp يتحدث وحده كل يوم.
- إذا ظهر خطأ في Actions أرسل لي نص الخطأ وأصلحه فوراً.
